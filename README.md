## 기능 목록

### 1. 룰렛

- 룰렛의 색상은 아래와 같이 5가지이며, 각 색상의 칸은 2.5%의 나올 확률을 가진다.
  - YELLOW, GREEN, BLUE, PURPLE, RED
- 배열 COLORS는 색상의 나올확률과 배당이 객체로 묶여있다.
- 각각의 색상은 1~1000 사이의 정수범위를 가진다. 생성된 난수가 색상의 정수범위 안에 속하면, 그 색상이 컴퓨터의 색상이 된다,

### 2. 게임 상태 - RouletteGame

- 게임 시작 시 자금은 10000원, 라운드는 0으로 초기화한다.
  - 자금은 사용자에겐 자릿수가 표현되지만, 게임내부에선 단순한 숫자형식이다.
- 베팅 시 베팅 금액을 자금에서 즉시 차감한다.(adjustMoney)
- 룰렛 결과로 베팅을 정산한다.
  - 라운드를 1 증가시킨다.(addRound)
  - 사용자와 컴퓨터의 색상이 같다면 승리하며, <베팅 금액 + 베팅 금액 \* 배당>을 자금에 더한다.(adjustMoney)
  - 사용자와 컴퓨터의 색상이 다르면 패배한다.
- 자금이 0원 이하인지 판별한다.(isGameOver)
- 다시 시작 시 자금과 라운드를 초기값으로 되돌린다.(handleRestart)

### 3. 유효성 검사 - isValid

- 유효하지않은 입력에 대해 사용자에게 경고한다.
  - 색상을 선택하지 않으면 에러를 발생시킨다.
  - 베팅 금액이 1 이상의 정수가 아니면 에러를 발생시킨다.
    - '^[1-9][0-9]\*$' 정규표현식을 사용하여, 맨앞이 0이 아니며 양수인 숫자를 판별한다.
      - 지수표현을 판별하기위해 입력값을 숫자로 변환하지않고, 문자열인 상태로 사용한다.
  - 베팅 금액이 현재 자금을 초과하면 에러를 발생시킨다.

### 4. 화면 업데이트 - RouletteGameView

- 버튼과 화면에 대한 DOM요소를 내부변수로 갖는다.
- 현재 자금을 천 단위 지릿수를 구별하여 표시한다.
  - .toLocaleString('ko-KR') 사용
- 현재 라운드를 표시한다.
- 기본 게임 화면
  - 다시 시작 버튼을 숨긴다.
- 베팅 시작
  - 베팅 버튼과 중단 버튼을 비활성화한다.
  - `룰렛을 돌리는 중...` 문구를 결과영역에 출력한다.
- 베팅 결과
  - `룰렛 결과: {색상}`을 출력한다.
  - 성공 시 `베팅 성공! +{획득 금액}원`, 실패 시 `베팅 실패! -{손실 금액}원`을 출력한다.
- 게임 종료 화면
  - `게임 종료`, `최종 자금: {금액}원`, `플레이한 라운드: {라운드 수}`를 출력한다.
  - 베팅 입력 영역(gameControl)을 숨긴다.
  - 다시 시작 버튼을 표시한다.
- 다시 시작
  - 베팅 입력 영역(gameControl)을 표시한다.
  - 색상, 베팅금액 칸을 초기화한다.
  - 초기화된 화면을 사용자에게 표시한다.

### 5. 게임 종료 - handleStop, finishGame

- 사용자가 게임중단 버튼을 눌렀을 때, 게임을 종료한다.
- 게임중단의 경우와 파산한 경우를 구별하여 게임을 종료한다.
  - 파산한 경우 베팅 결과 표출 후 `게임이 곧 종료됩니다.` 문구를 출력하며 2초 후 종료된다.

### 6. 다시 시작 - handleRestart

- 게임 클래스를 초기화한다.
- 게임뷰 클래스를 초기화한다.
- 다시 시작 버튼은 숨긴다.
